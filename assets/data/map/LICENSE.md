# Map data

The files in this folder are generated by `scripts/map/build.mjs` from:

- **Natural Earth** 1:10m cultural vectors (admin-0 countries, China point of view;
  disputed areas; admin-1 states and provinces). Public domain —
  <https://www.naturalearthdata.com/about/terms-of-use/>.
- **DataV GeoAtlas** (`geo.datav.aliyun.com/areas_v3`), boundary data from AMap
  (高德地图), provided for study and exchange (仅供学习和交流使用). Used for China's
  provinces, prefectures and the South China Sea dashed line.

The map is illustrative only and is not a surveying or official map.
