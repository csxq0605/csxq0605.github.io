# 让主页拿出证据，而不只是装饰

最值得放在学者或开发者主页上的创意功能，大多不是首页上的动画特效，而是**能被访客亲手验证的作品**：可以拖动的物理模拟、可以逐步回放的真实运行记录，以及带日期、会持续更新的研究日志。最受尊敬的一批个人站，例如 Bartosz Ciechanowski、Ten Minute Physics 和 Jon Barron，都把交互放在内容页或作品条目里，首页本身保持克制。几年前流行的"实时个人仪表盘"死得最快：Lee Robinson 的 /dashboard 已经重定向回首页，Paul Stamatiou 的 /stats 已返回 404，Spotify 在 2026 年又收紧了开发者 API。在 Jekyll + GitHub Pages 上，下面这些做法风险最低：构建时用 Liquid 或 GitHub Actions 把数据写成同源 JSON，交互用几 KB 的原生 JS 实现，不依赖 Google、Hugging Face、Steam 社区或 `*.vercel.app` 这类在中国大陆不稳定的域名。需要后端的东西（留言、点赞、实时光标、AI 对话）都要借第三方服务，而且在大陆基本都有可达性问题。这位主人研究长程可靠 agent，做过 PBF 流体游戏和 CUDA 框架，所以最有区分度的新功能是两样：一个**"进程被杀后断点续跑"的 Nexgent/ManySelves 运行回放页**，和一个**把 Taichi PBF 游戏移植到浏览器的流体解谜页**。其余高性价比的选项依次是：Barron 式的项目动图卡片、带日期的研究日志加 /now、复用 ⌘K 索引的 404 和彩蛋、面向 agent 的 llms.txt、构建时生成的 Steam 游戏陈列，以及二十四节气强调色。

> 核实口径：✅ 表示研究笔记记录该 URL 在 2026-10-26 从境外网络返回 HTTP 200，且功能已在页面 HTML 中确认或由站主原文描述；⚠️ 表示站点在线，但具体功能未能在本次核实（多为客户端渲染或凭记忆）；❌ 表示已下线、重定向或报错。所有"中国大陆可达性"判断都来自官方文档和社区报告，**没有一项是在大陆网络里实测的**。工作量与维护成本是笔者的估计。

## 交互与视觉：最好的模拟都放在内容页，不放在首页背景

物理与数学类个人站的共同特点，是把交互放进文章和作品里。Ciechanowski 的长文配有几十个可拖动的三维模拟。他的自行车一文只加载了 `/js/base.js` 和 `/js/bicycle.js` 两个自写脚本，外加 Google Tag Manager，没有任何第三方图形库 ([ciechanow.ski/bicycle](https://ciechanow.ski/bicycle/))。Matthias Müller（Position Based Fluids 论文合著者）的 Ten Minute Physics，每一集都配一个单文件 JS 演示，包括三摆、布料、"200 行"欧拉流体和 FLIP 水，源码头部带 MIT 许可 ([Ten Minute Physics](https://matthias-research.github.io/pages/tenMinutePhysics/index.html), [18-flip.html](https://matthias-research.github.io/pages/tenMinutePhysics/18-flip.html))。图形和仿真研究者的主页则大多是"可运行演示的画廊"，而不是一个满屏动画首页：Steven Wittens 的 acko.net 页头是 MathBox/WebGL 实时数学图形 ([acko.net](https://acko.net))，Evan Wallace 的 WebGL Water 至今仍可运行 ([madebyevan.com/webgl-water](https://madebyevan.com/webgl-water/))，David Li 的 3D FLIP 流体以 MIT 许可开源 ([dli/fluid LICENSE](https://raw.githubusercontent.com/dli/fluid/master/LICENSE))。对这位主人有一个提醒：Taichi 作者胡渊鸣的主页加载了 Google Fonts 和 cdnjs 资源 ([yuanming.taichi.graphics](https://yuanming.taichi.graphics))，照搬这类页面会把大陆不可达的依赖一起带进来。

库的体积决定了一个想法能否放上主页。实测 gzip 后，PavelDoGreat 的 WebGL 流体只有 **11.3 KB**（MIT），Rough.js 8.9 KB，matter.js 25.8 KB，three.js 171 KB，p5.js 249 KB 且为 LGPL-2.1，taichi.js 达到 **925 KB**，而且只支持 WebGPU（需 Chrome 113+），npm 上的最后更新停在 2023-05-23 ([PavelDoGreat README](https://raw.githubusercontent.com/PavelDoGreat/WebGL-Fluid-Simulation/master/README.md), [taichi.js README](https://raw.githubusercontent.com/AmesingFlank/taichi.js/master/README.md), [npm taichi.js](https://registry.npmjs.org/taichi.js))。结论是：taichi.js 在题材上最贴合，但只适合放在一个独立实验页，并配 GIF 兜底，绝不能进首页。

时段配色是视觉手法中性价比最高的一项。localghost.dev 在 06:30、08:00、19:30、21:00 四个节点之间渐变，到夜间切换为深色并出现像素星星。实现上用 `Temporal` 取时间、用 `color-mix(in oklch)` 混色，再用内联 `init.js` 防止闪屏；手动覆盖的选择存在 sessionStorage，作者自嘲这是"such an unnecessary touch"([localghost.dev](https://localghost.dev/blog/time-based-background-colour-transitions-with-temporal-and-css-color-mix/))。反面例子也很清楚：自定义光标、自动播放的音效和全屏粒子网络，在学术语境里都显得廉价。Josh Comeau 的音效之所以能接受，是因为他提供了显式的"Disable sounds"开关；他的点赞按钮依赖 MongoDB，多人彩虹依赖的 PartyKit 已经关停，所以只能退回单人模式 ([joshwcomeau](https://www.joshwcomeau.com/blog/how-i-built-my-blog-v2/))。这些都不是静态站能照搬的。无障碍方面，Maggie Appleton 和 Tim Holman 的 CSS 都显式处理了 `prefers-reduced-motion` ([maggieappleton.com](https://maggieappleton.com), [tholman.com](https://tholman.com))。本站的 `assets/css/site.css` 也已经有这条媒体查询，这一点做得对。

## 数据与状态：实时仪表盘消亡最快，手写的近况活得最久

个人数据仪表盘有一条清晰的"死亡记录"。Lee Robinson 那个展示 Spotify、GitHub 和浏览量的 /dashboard，现在经两次 307 重定向回到首页 ([leerob.com](https://leerob.com))；Paul Stamatiou 的 /stats 返回 404 ([paulstamatiou.com](https://paulstamatiou.com))；Simon Willison 的 /dashboard/ 跳到登录页，说明它是私有工具 ([simonwillison.net](https://simonwillison.net))。外部 API 也在不断变化。Goodreads 自 2020-12-08 起不再发放开发者 key ([Slashdot](https://developers.slashdot.org/story/20/12/17/1522242/goodreads-is-retiring-its-current-api-and-book-loving-developers-arent-happy))。Spotify 在 2026 年 2 月规定，开发模式应用的所有者**必须持有有效的 Premium 订阅**，每个应用最多 5 名用户 ([Spotify 迁移指南](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide))。Riot 的开发 key 每 24 小时失效，个人 key 明确"不得用于面向公众的应用"([Riot Developer Portal](https://developer.riotgames.com/docs/portal))。存活下来的是另一种形态：Derek Sivers 手写的 /now 页标着"Updated October 21st, 2026"([sive.rs/now](https://sive.rs/now))，Brian Lovin 的 /listening 是一份精选的"Music in rotation"列表，而不是实时播放流 ([brianlovin.com](https://brianlovin.com))。

在静态站上，这类功能可靠的架构只有一种：GitHub Actions 定时调用 API，密钥存在 Secrets 里，只把裁剪后的 JSON 写进 `_data/`，再由 Jekyll 在构建时渲染。浏览器只直接请求同时满足两个条件的接口：免 key，且带 CORS 头。笔记中实测带 `Access-Control-Allow-Origin: *` 的有 Last.fm、jogruber 的 GitHub 贡献 API 和 omg.lol；Steam、B 站 API 不带 CORS 头，WakaTime 需要鉴权。Actions 的定时任务有三个已知坑：最短间隔 5 分钟，整点经常延迟，而且**公开仓库 60 天没有活动就会被自动停用** ([GitHub Docs](https://docs.github.com/en/actions/writing-workflows/choosing-when-your-workflow-runs/events-that-trigger-workflows))。

/now 页最大的风险是过期。连 Patrick Collison 的书架页都挂上了"As of mid 2026, this page has not been updated in around 10 years"的横幅 ([patrickcollison.com/bookshelf](https://patrickcollison.com/bookshelf))。Juha-Matti Santala 观察到 nownownow 上很多页面停在 2020–2023 年，于是给自己定了按月更新的节奏 ([hamatti.org](https://hamatti.org/posts/scoping-the-now/))。缓解办法是在页首写日期，让构建时自动算出"N 个月前更新"的提示，再加一个日历提醒。还有一点值得注意："Bjergsen"是一位知名 LoL 职业选手的 ID。凡是挂这个名字的游戏挂件，都应写明"这是我借用的 ID，不是那位选手本人"，以免访客误认。

## 访客互动：静态站必须借一个后端，而大陆访客往往用不上

所有"访客留下痕迹"的功能都要存数据，GitHub Pages 自己存不了，只能三选一：借 GitHub（giscus、utterances），借一个托管服务（GoatCounter、Lyket、Applause、不蒜子），或者自己部署一个 Serverless 函数（Waline、Twikoo、cursor-party）。知名的定制方案几乎都依赖 Next.js 加数据库，而且已经开始消失：Lee Robinson 的留言板已经不在了 ([leerob.com/guestbook](https://leerob.com/guestbook))，Brian Lovin 的 AMA 仍然在线 ([brianlovin.com/ama](https://brianlovin.com/ama)) ✅。小型托管服务的脆弱性也有实证：cusdis.com 在 2026-10-26 返回 521，不蒜子主页返回 502（脚本本身仍可加载）([juejin](https://juejin.cn/post/7442554317052493850))。

在只读 Explore 页已有访客地图的前提下，给这位主人的判断是：访客互动不宜作为下一批重点。原因有二。第一，大陆访客是主要受众，而能免费、低维护跑起来的方案（giscus）恰恰要求 GitHub 登录。第二，匿名方案把站主变成了评论数据的控制者，还要承担审核工作。真要做，可以在已经接入的 GoatCounter 上开一个 `TOTAL` 计数（零新增依赖），或者模仿 Matt Webb，做一个"给路过的 AI agent 签名"的 `guestbook.txt`，这和主人的 agent 研究方向很契合。

## 导航、彩蛋与内容形态：一份 JSON 索引撑起半个网站

本站已经有 Ctrl/⌘K 搜索，这是同类设计里最显眼的一种。paco.me 的作者写了 React 库 `cmdk`，其页面 HTML 里能直接看到"⌘K""command menu"字样 ([paco.me](https://paco.me)) ✅。关键在于，同一份 Liquid 生成的 `search.json` 还能驱动随机页按钮、j/k 键翻页、`/terminal` 彩蛋和 404 页的"你是不是想找"。Gwern 的 404 页用 Levenshtein 距离猜测访客想访问的地址 ([gwern.net/design](https://gwern.net/design))。Bryan Braun 把常见彩蛋手法归为六类：源码注释里的 ASCII 画（Mozilla 曾在源码里给开发者留言）、带样式的 `console.log`、Konami 秘籍、悬停显现、搜索框魔法词、离线或电量等条件触发 ([Bryan Braun](https://www.bryanbraun.com/2018/04/01/several-ways-to-hide-easter-eggs-on-your-website))；[console.love](https://console.love) ✅ 收集了大量控制台彩蛋。终端式主页在 terminal.shop 上走到了极致，整个商店就是 `ssh terminal.shop` 后的 TUI ([terminal.shop](https://terminal.shop)) ✅。但终端式导航对无障碍和 SEO 都不友好，只适合作为可选彩蛋。另一端是 Gwern 的可递归悬浮预览和反向链接，作者自己承认那是"at the cost of great implementation complexity"([gwern.net/design](https://gwern.net/design))，对本科生主页来说投入产出不相称。

内容形态方面，slashpages.net 整理了约 60 种"斜杠页"惯例，如 /now、/uses、/ideas、/questions、/changelog、/colophon、/ai ([slashpages.net](https://slashpages.net)) ✅。经得起时间的是**只追加、自带日期**的形态，例如 Simon Willison 的 TIL：每篇是一个 Markdown 文件，日期取自 git 历史，由 Actions 自动生成索引，用来放"不值得写成一篇博客"的心得 ([simonwillison.net](https://simonwillison.net/2020/Apr/20/self-rewriting-readme/), [til.simonwillison.net](https://til.simonwillison.net)) ✅。Maggie Appleton 的数字花园给每篇笔记标上 🌱 幼苗、🌿 抽芽、🌳 常青三个阶段，并显示"种下"和"最近照料"的日期，用"imperfect by design"来化解完美主义 ([garden-history](https://maggieappleton.com/garden-history), [garden](https://maggieappleton.com/garden)) ✅。反面案例是数字花园 Jekyll 模板的演示站：它的"最近更新"栏最新一条停在 2023-10-24，这个栏目本身就在替站主宣告"已停更"([demo](https://digital-garden-jekyll-template.netlify.app)) ✅。

## AI 功能：拿得出真实证据的胜过"AI 分身"

"和我的主页聊天"已经是开发者作品集里的常见配置：用简历和项目文档做向量检索，再接 Gemini Flash、gpt-4o-mini 或 Groq 上的 Llama。但它们几乎都不能只靠 GitHub Pages 运行。与本站最接近的案例，前端放在 GitHub Pages，后端是部署在 Render 上的 Flask 加 FAISS ([Wantedly](https://www.wantedly.com/users/185320705/post_articles/1014645))。安全做法有一份较完整的参考：浏览器只请求自己的 Cloudflare Worker；用一个设了消费上限的专用 key；服务端校验 Turnstile；按访客哈希限流；系统提示词只在服务端拼装 ([gist](https://gist.github.com/theletterf/c650bcdbc94c985a3ed5b8e76e863ae6))。成本不是问题：Workers AI 每天免费 10,000 Neurons，超额即失败，相当于天然的硬上限 ([Cloudflare](https://developers.cloudflare.com:8443/workers-ai/platform/pricing))；有人实测约等于每天 80 次 Llama-3.3-70B 回答 ([flaviocopes](https://flaviocopes.com/cloudflare-workers-ai))。真正的风险在声誉上。Cursor 的客服机器人曾凭空编造公司政策 ([CX Today](https://www.cxtoday.com/conversational-ai/a-contact-center-chatbot-invents-company-policies-now-customers-want-out/))；Delphi 这类"AI 分身"平台要求上传证件，防止有人冒用他人身份建分身 ([The Decoder](https://the-decoder.com/ai-startup-delphi-wants-to-create-digital-clones-of-influencers/))。以第一人称"替我回答"的机器人，迟早会说出一句会被截图传播的错话。

大陆可达性让这件事更难。Hugging Face 自 2023 年起在大陆被封 ([Rest of World](https://restofworld.org/2026/china-open-source-ai-hugging-face-modelscope-moark/))，`hf.space` 也有不可达的报告 ([HF forum](https://discuss.huggingface.co/t/hf-space-has-been-blocked-in-china/170544))，OpenAI 的产品在大陆不可用 ([ENCA/AFP](https://www.enca.com/business/us-ai-giant-anthropic-bars-chinese-owned-entities))。浏览器内跑大模型也不现实：WebLLM 跑 Qwen2.5-0.5B 的 4-bit 版本要下载约 280–350 MB，需要 WebGPU，默认还从 HF 拉取权重 ([tinyweights.dev](https://tinyweights.dev/posts/run-llm-in-browser-webllm/))。机器可读的自我描述则便宜得多，但收益要说清楚。llms.txt 规范只要求一个 H1，可选摘要和链接分节 ([llmstxt.org](https://llmstxt.org/))；Ahrefs 对约 13.7 万个域名的统计显示，**97% 的 llms.txt 一次请求都没收到**，Google 也明确表示不支持它 ([PPC Land](https://ppc.land/llms-txt-adoption-rises-8-8x-but-97-of-files-get-zero-ai-requests/), [PPC Land](https://ppc.land/llms-txt-adoption-stalls-as-major-ai-platforms-ignore-proposed-standard/))。

## 给这位主人的八个新点子，按价值排序

排序依据四个标准：是否直接证明主人的研究能力（这是导师和招聘方最在意的），题材是否只有他做得出来，是否零后端且大陆可达，维护是否接近零。以下八项都**不是**本站已有功能；已有功能的改进单独列在后面。

| 排名 | 点子 | 对应类别 | 依赖 / 后端 | 大陆可达 | 首次工作量（估） | 维护 |
|---|---|---|---|---|---|---|
| 1 | "断电续跑"运行回放页 | AI / 内容形态 | 无 | ✅ 同源 | 2–4 天 | 低 |
| 2 | 浏览器版 PBF 流体解谜 | 交互实验 | 无（自写 WebGL2/JS） | ✅ 同源 | 3–7 天 | 低 |
| 3 | Barron 式项目动图卡片 | 内容形态 | 无 | ✅ | 1 天 | 每个项目一条 |
| 4 | 研究日志（TIL）+ /now + /questions | 时间与状态 / 内容 | 无 | ✅ | 半天 | 低，需固定节奏 |
| 5 | 404 / console / Konami / `/terminal` 彩蛋套装 | 导航与彩蛋 | 无（复用 ⌘K 索引） | ✅ | 半天到 2 天 | 0 |
| 6 | 面向 agent 的 llms.txt + JSON-LD + 预审 FAQ | AI | 构建期可选用 API | ✅ | 半天 | 极低 |
| 7 | Steam 游戏陈列（构建时生成） | 个人数据 | Actions + Steam key | ✅（链接除外） | 半天 | 低 |
| 8 | 二十四节气强调色 | 视觉 / 时间 | 无 | ✅ | 2–3 小时 | 0 |

**第一名是"断电续跑"回放页**，因为它把主人的核心论点变成了访客能自己点开的证据。挑一条真实的 Nexgent 会话（追加写入的 JSONL 日志加用量账本），其中进程中途被杀或断网，之后又恢复了。用 Actions 脚本脱敏后，渲染成一条可以逐步前进的时间线：计划、执行、检查点、**硬中断**、从日志重建状态、核对证据、继续执行；侧栏同步显示 token 和费用账本的变化。ManySelves 可以补一段 asciinema 录屏，内容是 `kill -9` 之后运行时自动恢复（自托管只需三个文件，见 [asciinema](https://docs.asciinema.org/manual/player/quick-start)）。这个形态已有先例：Simon Willison 把 Claude Code 会话发布成静态 HTML，当作"活是怎么干的"的证据 ([simonwillison.net](https://simonwillison.net/2025/Dec/25/claude-code-transcripts/))；IBM 的研究也指出，原始轨迹很难供人审阅，需要经过整理的可视化 ([IBM Research](https://research.ibm.com/publications/agent-trajectory-explorer-visualizing-and-providing-feedback-on-agent-trajectories))。主人的独特之处在于展示的是"恢复"这件事本身。回放用的是真实数据，不存在幻觉问题，也不需要 key，全部同源加载，大陆访客同样能看。

**第二名是浏览器版 PBF 流体解谜。** 它把简历上的 Taichi 项目变成访客能直接上手的作品，题材上也和"理论与应用力学"背景一致。具体做法是：参考 Ten Minute Physics 的 MIT 演示（它们用了空间哈希），把 PBF 内核改写成原生 JS 或 WebGL2，放在独立的 `/playground/` 页；默认显示静态海报帧，点击后才开始运行，离屏时暂停，`prefers-reduced-motion` 下只给一个"播放"按钮。不要用 taichi.js：它 925 KB gz、只支持 WebGPU、npm 自 2023 年起未再更新 ([npm](https://registry.npmjs.org/taichi.js))。如果移植工作量超出预期，退一步可以用 PavelDoGreat 的 11 KB 流体做"摸一下水面"的点击彩蛋 ([README](https://raw.githubusercontent.com/PavelDoGreat/WebGL-Fluid-Simulation/master/README.md))。它排在第一名之后，是因为 agent 可靠性才是主人当前的主线研究。

**第三名是 Barron 式项目卡片。** 仓库里已经有 `_data/projects.yml`，只需给每个条目加一张动图或短视频（Nexgent 的恢复过程、Tiny PyTorch 的训练曲线、PBF 关卡），再加一句白话 TL;DR，悬停时播放。Barron 的主页明言欢迎照抄源码，而且已有 Jekyll 移植版 ([jonbarron.info](https://jonbarron.info), [leonidk.com](https://leonidk.com/))。这是学术圈最被认可的条目排版，工作量约一天。

**第四名是带日期的研究日志，配 /now 和 /questions。** 研究日志是一个 `_til` 集合，每条记录一次调试 CUDA kernel 或修 JSONL 恢复 bug 的经过，只追加、日期自动生成，不会过期 ([simonwillison.net](https://simonwillison.net/2020/Apr/20/self-rewriting-readme/))。/now 页顶部写明日期，构建时自动算出距今几个月，再在日历里设一个每月提醒，防止它变成 Collison 书架那样的"化石"。/questions 列出主人关心的开放问题，例如"长程 agent 的恢复语义能否形式化"，并邀请来信讨论 ([patrickcollison.com/questions](https://patrickcollison.com/questions))。如果愿意，还可以附一节"被拒记录"，Haushofer 的失败简历证明这种诚实很容易被人记住 ([WHYY/AP](https://whyy.org/articles/princeton-prof-puts-cv-of-his-failures-online-to-give-perspective))。

**第五名是一套复用 ⌘K 索引的彩蛋。** 本站目前没有 `404.html`，可以补一个按 Levenshtein 距离推荐地址的 404 页 ([gwern.net/design](https://gwern.net/design))。控制台打印一条 ASCII 招呼，再带一句"session restored from checkpoint"。Konami 序列打开 `/terminal`，里面的命令与主人的研究呼应：`ls projects`、`cat now.md`、`resume --from last-checkpoint`。这样彩蛋本身就在讲主人的研究故事，而且零维护。

**第六名是面向 agent 的机器可读自述。** 内容包括 Liquid 生成的 `/llms.txt`、关键页面的 `.md` 副本，以及带 `sameAs`（GitHub、Scholar、ORCID）的 `Person` JSON-LD。对一位 agent 研究者来说，"我的主页对 agent 友好"本身就是一种立场表达。但要接受数据：97% 的 llms.txt 从未被请求过 ([PPC Land](https://ppc.land/llms-txt-adoption-rises-8-8x-but-97-of-files-get-zero-ai-requests/))，所以把它当作一小时的卫生工作即可，不能指望它带来曝光。如果想要问答效果，可以在 Actions 里根据简历和 README 生成 20–50 条问答，由主人逐条审阅后作为静态 FAQ 发布。这比实时机器人安全，也比它便宜。

**第七名是构建时生成的 Steam 游戏陈列。** 照搬 steam-box 的思路 ([steam-box](https://github.com/XCwosjw/steam-box))：Actions 每天拉一次总时长和最近游玩，只写入游戏名和小时数，由 Jekyll 渲染成卡片。卡片上注明"Bjergsen 是借用的职业选手名，这是我自己的账号"。页脚的 Steam 链接对大陆访客打不开，因为 Steam 社区自 2017 年起被封 ([Wikipedia](https://en.wikipedia.org/wiki/List_of_websites_blocked_in_mainland_China))，但构建时渲染的卡片照样可见。不建议接入 Riot 战绩：个人 key 禁止面向公众，开发 key 每天都会失效 ([Riot](https://developer.riotgames.com/docs/portal))。

**第八名是二十四节气强调色。** 在现有石板蓝的基础上，按当前节气微调强调色的色相，并在页脚写上"今日：霜降"。思路借鉴 seasonal-css 的"一年对应色轮" ([jes/seasonal-css](https://github.com/jes/seasonal-css)) 和 localghost.dev 的时段配色 ([localghost.dev](https://localghost.dev/blog/time-based-background-colour-transitions-with-temporal-and-css-color-mix/))，但不加任何动画，适合学术语境，也对中文访客有文化上的亲切感。唯一的工作是逐一检查 24 组配色在深浅两种模式下的对比度。

### 已有功能怎么改进

Explore 页上的阻尼振子可以扩展成一个"力学小实验"系列，如悬臂梁挠度、Chladni 板振型、莫尔圆。这些都能用原生 SVG 或 canvas 写成，而且在学生主页上几乎找不到先例；做出来以后，Explore 就从"杂物页"变成了主人专业背景的展示窗口。访客地图依赖的 `visitor-atlas` 定时工作流每小时运行一次。要注意，定时任务只在默认分支上执行，而且**公开仓库 60 天无活动会被自动停用** ([GitHub Docs](https://docs.github.com/en/actions/writing-workflows/choosing-when-your-workflow-runs/events-that-trigger-workflows))；机器人强推到 `visitor-stats` 分支算不算"活动"，笔记里没有定论，所以要在文档里提醒自己定期检查。开启 GoatCounter 后，可以顺手用它的 `TOTAL` 路径显示一个无 JS 的总访问数 ([GoatCounter](https://www.goatcounter.com/help/visitor-counter))。⌘K 搜索的条目目前写在 `search.html` 里：项目条目由 Liquid 循环 `site.data.projects` 生成，其余入口是手写的。改成由 Liquid 统一生成 `search.json` 后，新增页面会自动进入索引，第五名的彩蛋也能直接复用。深浅色切换可以加第三档"跟随系统"，再加一个阅读模式，参照 Gwern 的做法 ([gwern.net](https://gwern.net))。模联人格测试可以在结果页增加一张可分享的结果卡片，不过这是笔者的推论，没有找到先例。最后是依赖清理：`_includes/head/custom.html` 从 cdnjs 加载 MathJax，Scholar 统计脚本保留了 jsDelivr 路径，而 jsDelivr 已于 2021-12-20 失去中国 ICP 备案 ([springdoc 论坛](https://forum.springdoc.cn/t/topic/4657))。cdnjs 在大陆的可达性本次未核实，建议一并改为自托管。

## Conclusion

这次调研最反直觉的发现是，个人主页上最能"拿出证据"的功能，往往也是最省心的功能。真实运行回放、单文件物理演示和只追加的研究日志，既不需要后端，也不依赖会被封锁的域名，更不会因为某家 API 改了政策而一夜失效；而那些看起来最"实时"、最"智能"的功能，比如 Spotify 正在播放、AI 分身和多人光标，恰恰最依赖第三方服务，最容易在大陆失效，也最容易变成停更的遗迹。对一位研究"硬中断后可恢复"的 agent 研究者来说，静态、同源、由构建期数据驱动的架构，本身就是他研究理念在网站上的翻版。

尚未解决的问题集中在测量上：所有大陆可达性判断都还没有实测，至少应该用国内拨测工具确认 `github.io`、cdnjs 和 `workers.dev` 的实际情况，再决定是否引入任何运行时第三方服务。另外，学术圈对"好玩的主页"究竟怎么看，目前没有任何调查数据，排序依赖的是先例与推理，而不是访客研究。最稳妥的策略是：默认保持安静，把个性放在可以点开的作品里，不放在首页的特效里。
