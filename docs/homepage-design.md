# 个人主页设计说明与调研

更新：2026-10-25

## 1. 设计前提

首页结构保持本人原来的排版：**左侧个人资料，右侧按顺序阅读**。

> About Me → Research Interest → News → Education → Experience → Projects → Honors

所有原有文字完整保留（逐词核对，没有删减），仅做了三处结构调整：

- 七个章节的 emoji 标题改为编号标题（01–07），锚点 ID 不变，`/#projects` 等旧链接仍然有效；
- About Me 补上了标题，与其他章节一致；
- 每个项目改为独立小节，标题仍链接到仓库，并在末尾增加一个明确的仓库按钮（如 `csxq0605/Nexgent ↗`）。

这次重做的重点是视觉、导航和附加页面，而不是调整内容顺序。

## 2. 参考对象与证据

以下数据均来自公开源码（括号内为本次核对时的 commit）。官网直连在当前环境中受限，因此以源码为准，不引用记忆中的旧版本。

| 参考 | 布局要点（源码） | 本站采用 |
|---|---|---|
| Minimal Light（yaoyao-liu, `dd114c3`） | 960px 版心；`header` 232px 固定在左侧，`section` 650px 正文在右；≤960px 时侧栏变为普通流，排在正文前 | 左侧资料栏＋右侧正文；手机端资料在正文前 |
| AcademicPages（`7b95833`） | 左侧作者栏，较宽屏幕切换为窄侧栏；本站原主题即源自这一体系 | 保留“侧栏是名片”的阅读习惯 |
| Jon Barron 主页（`155213d`） | 一张 `max-width: 800px` 的表格：头像在右侧 37%，正文在左；整页单色、文字优先 | 头像小而圆，正文优先；不堆装饰 |
| Tufte CSS（`b5d7b7b`） | 正文栏宽限定为 `width: 55%`，正文 1.4rem / 2rem 行高；以有限行长保证长文可读 | 正文栏限制在 680px（约 80 个英文字符） |
| al-folio（`f2a2765`） | 页面拆成 about / news / projects / repositories / books / cv 等；评论用 Giscus | 主页之外的内容放到独立页面（Explore、CV） |
| GitHub Minimal（`c27a30c`） | 与 Minimal Light 同源的双栏结构 | 同上 |

结论：学者主页的成熟做法是“**固定身份信息 + 有限行长的连续正文**”。本站原排版已经是这种结构，问题主要在视觉层级、导航和移动端，而不在内容顺序。

## 3. 原版存在的问题

1. 标题层级弱：emoji 标题与正文字号接近，长页面中难以定位章节。
2. 正文行长偏长，经历和项目段落像一整块文字。
3. 项目只有标题链接，读者不容易发现“这里可以进仓库”。
4. 窄屏导航依赖旧主题的折叠菜单，手机上会占据较多空间。
5. 旧模板即使未配置 Google Analytics，也会加载 gtag 脚本。

## 4. 视觉方案

| 项目 | 取值 | 理由 |
|---|---|---|
| 版心 | 1080px；侧栏 212px，栏间距 72px，正文最大 680px | 参考 Minimal Light 的双栏比例和 Tufte 的有限行长 |
| 标题字体 | Newsreader（OFL，自托管，仅保留拉丁字符，约 124 KB） | 适合学术主页的衬线字体，用于姓名、章节标题与项目名 |
| 正文字体 | 系统无衬线字体，16px / 1.72；中文回退到苹方或思源 | 中英文混排时加载快、清晰稳定 |
| 配色（浅色） | 纸色 `#fbfaf7`、正文 `#353d40`、强调色石板蓝 `#33607a` | 安静、偏学术，只用一个强调色 |
| 配色（深色） | 背景 `#191e21`、正文 `#d3d9da`、强调色 `#9cc2d7` | 支持手动切换，并记住选择 |
| 章节 | 等宽编号 `01`–`07`＋衬线标题＋细分隔线 | 不依赖 emoji，也能快速定位 |
| 日期 | 等宽小标签，如 `2026.06` | News、Education、Honors 更容易按时间扫读 |

对比度（WCAG AA 要求正文 ≥ 4.5:1）：

- 浅色：正文 10.6、辅助文字 5.5、最浅灰 4.9、链接 6.5；
- 深色：正文 11.8、辅助文字 7.5、最浅灰 5.0、链接 8.9。

检查中发现，第一版最浅的灰色只有 2.9:1，已经调深。

## 5. 导航

- **桌面（> 1140px）**：顶部直接显示七个章节，当前阅读章节带下划线；`Projects` 是下拉菜单，可回到项目章节，也可直接打开三个仓库。另有 Explore、CV、搜索和明暗切换。
- **较窄屏幕和手机**：合并为一个 `Menu`，包含七个章节、Explore／CV，以及三个仓库链接；手机端菜单宽度贴合屏幕，所有触控目标至少 44px。
- **快速搜索**：按 `Ctrl / ⌘ K` 或 `/` 打开，支持中英文关键词，例如“教育”“地图”“简历”“Nexgent”。方向键可选择结果，Enter 打开，Esc 关闭。
- 禁用 JavaScript 时，所有内容和原生折叠菜单仍可使用。

## 6. 趣味内容：调研后的取舍

| 想法 | 结论 | 原因 |
|---|---|---|
| 访客来源地图 | **已做，暂未开启统计** | 使用 GoatCounter 统计国家／地区访客数，不保存或展示 IP。地图界面和数据接口已完成，启用方法见 `visitor-statistics.md` |
| 世界地区探索度（个人足迹） | **已做** | 与访客地图共用一张地图，分为两个标签页；统计国家／地区数及占 249 个 ISO 国家与地区的比例。目前只有常驻地北京，旅行地点需要你填写真实记录 |
| 可交互小实验 | **已做：阻尼振子** | 与力学专业直接相关：拖动阻尼比 ζ，可以看到欠阻尼、临界阻尼和过阻尼三种响应，支持播放、单步和重置。公式为解析解，测试会核对 ζ=0、ζ=1 等已知结果 |
| 模联人格测试 | **保留并加入口** | 原有页面不改，从侧栏和 Explore 可以进入 |
| 北京时间与求职状态 | **已做** | 放在侧栏中，占用空间小，同时提供实用信息 |
| ClustrMaps / Flag Counter 小组件 | 不采用 | 第三方图片样式无法与本站统一，深色模式下效果较差 |
| Giscus 留言板 | 暂缓 | 访客需要 GitHub 登录，也需要开启 Discussions；适合以后需要互动时再加 |
| Now／Uses／书架页 | 暂缓 | 需要你提供真实内容，不能由我编造；页面结构可以很快补上 |
| 研究手记 | 暂缓 | 同上，至少要有一篇真实的手记再上线 |

## 7. 如何维护

- **改正文**：仍然编辑 `_pages/about.md`，写法与以前相同。
- **项目菜单**：编辑 `_data/projects.yml`，用于顶部下拉菜单、手机菜单和搜索。
- **添加去过的地方**：在 `_data/explore.yml` 的 `travel:` 下添加条目，文件中有示例。
- **开启访客统计**：见 `docs/visitor-statistics.md`。
- **检查**：构建后执行 `node tests/verify_site.js http://127.0.0.1:4100`（浏览器测试），以及 `python3 -m unittest discover tests`（统计导出测试）。

## 8. 已验证

- 1440、1141、1140、1024、761、760、390、320px 八种宽度下均无横向溢出；七个章节顺序和三个仓库链接正确；菜单、当前章节、搜索和主题记忆均通过测试。
- Explore：个人足迹、未开启统计时的状态、明确标注的示例数据、键盘切换标签，以及真实数据、异常数据和服务器错误三种接口情况均通过测试。
- 阻尼振子：已知解析解、过阻尼单调衰减、播放、暂停和单步均通过测试。
- CV 中英文切换，以及无 JavaScript 时的浏览均通过测试。
- 统计开启后的生产构建：每页只包含一个计数脚本，公开站点不包含 token，`scripts/` 和 `tests/` 不会发布。
